# Demo personas

Each file is a `PersonaFile` (`src/integrations/types.ts`): typed slices of engine `Facts` per simulated registry,
loaded by `PersonaStore` → adapters → `assemble`. All people are fictional; no PESEL, addresses or employer names
(payers are `payer-1`). Money in grosze, dates ISO, 2026 parameters (min. wage 4 806 zł, min. declared base 5 652 zł,
preferential base 1 441,80 zł, debt threshold 48,06 zł). Each title carries the 12 months before the relevant month.
